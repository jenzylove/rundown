## Phase 1. Simulator and stats engine (21 to 22 Oct)
- Match model: possession chains driven by team tactical profiles, with 10 Hz movement
  and planted stories saved as the answer key.
- Stats engine as pure functions with unit tests.
- **Check:** `pytest` green; a 90 min seed exports events, tracking and the answer key; a stats
  snapshot at 45' matches hand-computed values for a fixed seed.

## Phase 2. Agent crew (22 to 23 Oct)
- Six agents on Agent Framework with Foundry models, using Cosmos DB as shared state.
- The Verifier gate, retries and recovery.
- **Check:** a full half on a seed produces a locked rundown in valid Overlay Script; the trace is
  visible in Foundry; the kill-the-Telestrator run recovers.
- **Status 21 Oct: done, except Foundry-side traces and Cosmos.** Locked, verified rundowns on four
  seeds in two cuts, lock median 1.9 s after the whistle; the kill-the-Telestrator run recovers with
  every segment verified (`docs/CREW.md`). The trail is ours (API, WebSocket, desk); Foundry tracing
  waits on the Application Insights connection string. The shared store is in memory, mirrored to
  Cosmos DB since 22 Oct (agents don't read from Cosmos yet).

## Phase 3. Renderer, voice and studio (23 to 24 Oct)
- Pitch replay, overlay playback, Speech voice-over with captions, approval desk, EN/ES
  and home/away cuts.
- **Check:** headless browser screenshots of a segment mid-play in dark and light; audio plus captions
  in sync within 150 ms.
- **Status 21 Oct: voice-over done.** Each segment's script is voiced by Azure AI Speech
  (`studio/voice.py`), re-timed to the audio, and played in step with the studio clock with
  word-by-word captions. Headless Chromium, both themes, EN and ES: the voice runs a steady 86 ms
  ahead of the studio clock (max 89 ms, 160 samples; re-sync past 150 ms). Add S3's word-timing error
  (median 37 to 64 ms, max 150 ms) and the worst case can pass 150 ms, so this is close, not
  comfortably inside. Screenshots: `docs/spikes/img/studio-voice-*.png`. Still to do in Phase 3: MP4
  export, FR/PT cuts, name pronunciation (S3).

## Phase 4. Azure deploy and live stream (24 to 25 Oct)

- **Check:** the public URL runs a fresh seed end to end, with no local machine involved.
- **Status 22 Oct: done.** Live at https://rundown.mangowave-7522f242.swedencentral.azurecontainerapps.io. Every match streams through Event Hubs

## Phase 5. Evals and proof (25 Oct)
- Story recall, precision, grounding, slot fit, and the baseline, on 10+ seeds. Publish the
  first misses and the fixes.
- **Check:** the eval table lands in README and `/proof`, generated by a script anyone can rerun.
- **Status 22 Oct: measured and published** (`docs/EVALS.md`, README, `/proof`). On 12 fresh seeds:
  detectors spot 70% of planted first-half stories; story recall agents 39% against the rules
  baseline's 52% (agents 52%, 48%, 39% over three runs); grounding 100% for both; Foundry
  groundedness judge about equal. First misses fixed: a lone talking point broke the 60 s schema
  limit (the agents aired nothing); the judge lacked the facts' detail. Open: the agent Producer
  picks worse than the baseline, detection misses 30%, and the Foundry run can't be logged to the
  project (the deploy identity lacks the data action).
