# Rundown: build plan

Deadline: **27 Oct 2026, 11:59 pm PT (28 Oct, 06:59 UTC)**. Plan to submit by 27 Oct, 18:00 UTC
so there is a buffer.

Each phase ends with a check that proves it is done.

## Phase 0. Spikes (21 Oct)
| Spike | Question | Needs | Status |
|---|---|---|---|
| S1 Telestration | Can a browser renderer play a timed overlay script over 10 Hz synthetic tracking smoothly, and does it read like TV? | nothing external | needs a spike |
| S2 Agents on Foundry | Can Agent Framework (Python) call a Foundry model with structured output reliably enough to emit valid Overlay Script JSON? | Azure + Foundry | needs a spike |
| S3 Speech | Do Azure AI Speech neural voices return word timings in EN/ES/FR/PT for caption sync? | Azure | known (documented), confirm |

**Check:** `docs/spikes/<name>.md` for each, with question, run, output, verdict.

## Phase 1. Simulator and stats engine (21 to 22 Oct)
- Match model: possession chains driven by team tactical profiles, with 10 Hz movement
  and planted stories saved as the answer key.
- Stats engine as pure functions with unit tests.
- **Check:** `pytest` green; a 90 min seed exports events, tracking and the answer key; a stats
  snapshot at 45' matches hand-computed values for a fixed seed.

## Phase 2. Agent crew (22 to 23 Oct)
- Six agents on Agent Framework with Foundry models, using Cosmos DB as shared state.
- The Verifier gate, retries and recovery.
- **Check:** a full half on a seed produces a locked rundown in valid Overlay Script; the trace is
  visible in Foundry; the kill-the-Telestrator run recovers.

## Phase 3. Renderer, voice and studio (23 to 24 Oct)
- Pitch replay, overlay playback, Speech voice-over with captions, approval desk, EN/ES
  and home/away cuts.
- **Check:** headless browser screenshots of a segment mid-play in dark and light; audio plus captions
  in sync within 150 ms.

## Phase 4. Azure deploy and live stream (24 to 25 Oct)
- Bicep for Container Apps, Event Hubs, Cosmos DB, App Insights; GitHub Actions deploy.
- `/demo` and `/proof` live.
- **Check:** the public URL runs a fresh seed end to end, with no local machine involved.

## Phase 5. Evals and proof (25 Oct)
- Story recall, precision, grounding, slot fit, and the baseline, on 10+ seeds. Publish the
  first misses and the fixes.
- **Check:** the eval table lands in README and `/proof`, generated by a script anyone can rerun.

## Phase 6. Design pass, audit, approval (25 to 26 Oct)
- Design pass (own identity, rendered dark and light, screenshots to the user).
- `release-readiness-audit`, then fix what's real.
- **Gate: user approves the live product.**

## Phase 7. Launch (26 to 27 Oct)
- README with the judge fast path, demo video (<2:00, YouTube), launch reel, submission text.
- Repo goes public after a secret scan.
- **Check:** every line of `SUBMISSION_CHECKLIST.md` ticked from the live app; submitted.

## Risks and unknowns
| Risk | Type | Plan |
|---|---|---|
| Microsoft account creation blocked (Azure, Foundry and portal all need it) | **blocker, external** | User retries from another network once the block clears. Until then, Phases 0 S1, 1 and 3 run with no Azure. |
| This cloud session's network denies `models.github.ai` and `management.azure.com` | **blocker, environment** | Add Azure and GitHub Models hosts to the environment's allowed domains, or run the Azure parts from the user's machine. |
| Telestration doesn't look like TV | needs a spike (S1) | If S1 fails, segments become freeze-frame plus zones and labels, with the change agreed with the user first. |
| Models emit invalid overlay JSON | needs a spike (S2) | Structured output plus a schema validator, then Verifier retry, then drop the segment. |
| Simulator looks unrealistic | known | Tune against public aggregate norms (pass completion, shots per match), sourced in the README. |
| Free Azure credit limits | known | Small model deployments, scale to zero on Container Apps, delete after judging. |
